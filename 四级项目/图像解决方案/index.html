图像解决方案 · 字体图标与 SVG

本页为四级项目"图像解决方案"：上导航采用 SVG（symbol 精灵 + use 复用，CSS 控制描边颜色与尺寸）； 下导航采用 个性化字体图标（自绘路径生成的 iconfont 字体文件，CSS 通过 font-size / color 修饰）， 两种技术互相区别。下导航固定在页面底部，flex:1 自适应宽度，多视口下均正常显示。

两种图像技术对比演示

同一组图标，分别用字体图标与 SVG 实现，并用 CSS 修饰其大小与颜色。

方案一字体图标（iconfont）

由自绘 SVG 路径生成的个性化字体文件（wyh_iconfont.ttf / .woff），图标即字符： CSS 用 font-size 改大小、color 改颜色。用于本页下导航。

方案二SVG（symbol + use）

页面顶部内联 SVG 精灵，<use> 按需复用；CSS 可直接修饰描边（stroke）、填充（fill）与线宽， 支持悬停变色、旋转等更精细的控制。用于本页上导航。

校园服务快捷入口（字体图标）

字体图标同样可用于内容区：栅格自适应排列，悬停上浮。
