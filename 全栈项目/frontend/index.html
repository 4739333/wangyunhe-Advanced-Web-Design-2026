WangAI 智能聊天系统

前后端分离全栈架构：原生 HTML / CSS / JavaScript + Node.js / Express 中间层 + SQLite 数据库。
调用 DeepSeek 大模型 API，支持多轮上下文、SSE 流式输出与中断、历史压缩摘要与会话管理。

姓名：王云鹤 学号：24002060416 项目名称：LLM 应用设计（AI 聊天） 项目类别：自选

AI 流式聊天

后端代理大模型，SSE 流式输出可中断，Markdown 渲染，消息落库与历史回放。

本地聊天

不依赖大模型的本地规则回复引擎，会话与消息同样持久化在 SQLite。

会话历史

按用户查看全部会话与消息条数，支持重命名、删除与详情查看。

知识库问答 (RAG)

上传 doc / docx / txt 解析入库，检索命中资料注入提示词，智能客服 SSE 流式回答。

科技新闻

新闻数据存于 wang_news 表，前端通过 GET /api/news 获取并渲染列表。

图文展示

图文数据存于 wang_gallery 表，图片由文生图服务生成，GET /api/gallery。

AI 资讯

数据存于 Supabase 远程 PostgreSQL（wang_ai_news 表），前端原生 fetch 直连 REST 匿名只读。

会话详情示例

只读消息回放页（示例加载 1 号会话），任意会话可从历史页一跳进入。

后端接口清单（统一响应 {code, msg, data}，端口 416 = 学号后三位）

GET /api/users用户列表
GET /api/sessions?wang_user_id=会话列表（含消息数）
POST /api/sessions新建会话　PUT /api/sessions/:id重命名会话
DELETE /api/sessions/:id删除会话（级联删消息）
GET /api/sessions/:id/messages会话消息回放
POST /api/chat本地规则引擎聊天
POST /api/ai/chat大模型非流式对话
POST /api/ai/chat/stream大模型 SSE 流式对话（落库 + 压缩摘要）
POST /api/kb/upload知识库文件上传解析　GET /api/kb/docs文档列表　DELETE /api/kb/docs/:id删除文档
POST /api/kb/search知识库检索　POST /api/kb/chat/streamRAG 智能客服 SSE 问答
GET /api/news科技新闻列表
GET /api/gallery图文展示列表
Supabase RESTAI 资讯列表（服务器端为 Supabase 远程 PostgreSQL，表 wang_ai_news，前端原生 fetch 匿名只读，见根目录 database.md）
