JavaScript 程序结构：条件与循环

作者：王云鹤 —— 演示 if...else / switch 条件结构与 for / while / do...while 循环结构

一、条件结构

1. if...else（判断分数等级）

if (wyh_score >= 90) { ... } else if (wyh_score >= 60) { ... } else { ... }

2. switch（数字转星期）

switch (wyh_day) { case 1: wyh_name = "星期一"; break; ... default: wyh_name = "输入有误"; }

二、循环结构

1. for 循环（1 ~ n 累加求和）

var wyh_sum = 0; for (var wyh_i = 1; wyh_i <= wyh_n; wyh_i++) { wyh_sum += wyh_i; }

2. while 循环（1 ~ n 阶乘）

var wyh_fact = 1, wyh_j = 1; while (wyh_j <= wyh_n) { wyh_fact *= wyh_j; wyh_j++; }

3. do...while 循环（先执行后判断，输出偶数）

var wyh_k = 2; do { wyh_out += wyh_k + " "; wyh_k += 2; } while (wyh_k <= 20);
知识点小结：程序结构分为顺序结构、条件结构（分支）和循环结构三种。 条件结构按条件选择执行路径（if...else、switch）；循环结构重复执行代码块（for、while、do...while）， 可用 break 跳出循环、continue 跳过本次循环。注意 do...while 至少执行一次循环体。
