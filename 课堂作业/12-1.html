CSS 变量演示

使用 CSS 自定义属性（Custom Properties）管理颜色、尺寸等主题值

1. 定义变量

在 :root 中声明全局变量，供整个页面引用

:root {
    --wyh_primary: #d9684e;
    --wyh_ink: #19302c;
    --wyh_radius: 12px;
}

2. 使用变量

通过 var() 函数引用变量值

.wyh_btn {
    color: var(--wyh_ink);
    border-radius: var(--wyh_radius);
}

3. 变量修改变更

局部作用域覆盖全局变量，实现主题切换

.wyh_interactive {
    --wyh_local: #4e8d7b;
}
body.wyh_dark {
    --wyh_paper: #1a2521;
    --wyh_ink: #e8f0ea;
}
