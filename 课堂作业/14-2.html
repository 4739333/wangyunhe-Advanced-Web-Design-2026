JavaScript 六种基础数据类型

基础类型（Primitive Types）的值不可变，按值访问，共六种

String 字符串

文本

表示文本数据，可用单引号、双引号或反引号包裹，反引号支持 ${} 模板插值。

const wyh_str = '王云鹤';

Number 数字

数值

整数与浮点数统一为 Number 类型，还支持特殊值 NaN、Infinity。

const wyh_num = 42; const wyh_float = 3.14; const wyh_not = 0 / 0;

Boolean 布尔

逻辑

只有两个值：true 与 false，常用于条件判断。

const wyh_yes = true; const wyh_no = false;

Undefined 未定义

空缺

声明了变量但未赋值时，其默认值就是 undefined。

let wyh_empty;

Null 空值

空缺

表示"有意为空"，需要手动赋值 null；typeof 的历史遗留缺陷会返回 object。

const wyh_none = null;

Symbol 符号

ES6

ES6 新增，表示独一无二的值，主要用作对象属性的键，避免命名冲突。

const wyh_sym1 = Symbol('id'); const wyh_sym2 = Symbol('id');
